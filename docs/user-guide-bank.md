# HaliCred Bank Portal User Guide

## Overview

The HaliCred Bank Portal provides financial institutions with AI-verified green credit scoring and risk assessment tools for SME lending. This guide covers how to use the platform to review loan applications, assess green credentials, and make informed lending decisions.

## Getting Started

### Account Setup

1. **Institution Registration**
   - Contact HaliCred sales team for institutional account
   - Complete KYC and regulatory compliance verification
   - Receive bank-specific login credentials

2. **User Account Creation**
   - Bank administrator creates user accounts
   - Assign appropriate roles and permissions
   - Set up two-factor authentication

3. **Portal Access**
   - Web Portal: https://bank.halicred.com
   - Login with institutional credentials
   - Complete initial security verification

### Green Score Analysis

#### Understanding Green Scores

**Score Ranges and Risk Correlation**:
- **80-100**: Excellent (Low risk, premium terms)
- **70-79**: Good (Below average risk)
- **60-69**: Fair (Average risk)
- **50-59**: Poor (Above average risk)
- **Below 50**: Very Poor (High risk, manual review)

#### Pillar Analysis

**Energy Efficiency (25% weight)**
- Renewable energy adoption
- Equipment efficiency ratings
- Energy conservation practices
- Utility bill improvements

**Waste Management (20% weight)**
- Waste reduction initiatives
- Recycling programs
- Circular economy practices
- Waste cost savings

**Sustainable Practices (25% weight)**
- Environmental certifications
- Sustainable sourcing
- Green operations
- Supply chain sustainability

**Carbon Footprint (30% weight)**
- Emission reductions achieved
- Carbon-neutral initiatives
- Transportation efficiency
- Climate impact mitigation

### Evidence Verification

#### AI-Processed Evidence

Each piece of evidence includes:

**Processing Results**
- OCR text extraction
- Image analysis results
- Equipment identification
- Supplier verification

**Confidence Scoring**
- High (80-100%): Verified and reliable
- Medium (60-79%): Good with minor uncertainties
- Low (40-59%): Requires manual review
- Very Low (<40%): Likely invalid

**Impact Calculation**
- Emission reduction quantification
- Green score contribution
- Carbon credit estimation
- Financial impact assessment

## Troubleshooting

### Common Issues

#### Green Score Discrepancies
**Symptoms**: Green score seems too high/low for the evidence
**Resolution**:
1. Review individual evidence items
2. Check confidence scores for each piece
3. Validate high-impact items manually
4. Contact HaliCred support if discrepancy persists

#### Technical Issues
**Symptoms**: Platform running slowly or errors occurring
**Resolution**:
1. Clear browser cache and cookies
2. Try different browser or incognito mode
3. Check internet connection stability
4. Contact technical support with error details

#### Application Processing Delays
**Symptoms**: Applications stuck in processing status
**Resolution**:
1. Check for required documentation completeness
2. Verify all approval workflows are completed
3. Review for any pending manual verification tasks
4. Escalate to supervisor if delays continue
